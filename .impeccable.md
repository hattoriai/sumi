## Design Context

### Users
The Hattori app team uses this private component library to build and review
consistent interfaces across Itazu, Toryo, and other Phoenix apps.

### Brand Personality
Restrained, editorial, precise. The repository README is the source for
Sumi's established design rules.

### Aesthetic Direction
Ink is canonical; Paper and Snow are supported. Cormorant Garamond display
text and Outfit interface text, blade accents, hairline borders, and nearly
square corners. Previews show real components with generous reading space.

### Design Principles
- Import shared component CSS and JavaScript directly.
- Pair every state with words or shapes; preserve keyboard interaction.
- Exercise every theme, narrow screens, and reduced motion.
- Keep preview scaffolding separate from the distributed design system.
- Use fictional sample content for the internal library.
